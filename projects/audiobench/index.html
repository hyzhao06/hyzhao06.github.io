    统一组合数据 LoRA

    从原始基座模型出发，使用 CDSD、EasyCall、TORGO、UA-Speech 的组合训练集进行统一适配；疾病组用于微调，健康组独立评估。

    模型
    Qwen2.5 · Phi-4 · Whisper
    适配
    LoRA rank 16 / alpha 32 / dropout 0.05
    训练
    BF16 · 有效 batch 32 · learning rate 1e-4
    评测
    WER / CER / SER / SemScore / S-D-I
    数据组织

    固定划分与分层抽样

    按说话人和录音组隔离训练、验证、疾病测试与健康测试；组合训练使用预先固定的抽样计划，保证跨模型可比较。

    • 疾病测试：52,073 条
    • 健康完整队列：21,055 条
    • 健康前后可配对子集：13,474 条
    • 所有前后对比均显式记录样本数与覆盖率

    单独数据集微调方法

    每个模型分别从原始基座权重出发，仅使用一个数据集的训练部分进行 LoRA 微调，再在四个数据集的冻结测试集上评估，形成 4 模型 × 4 训练集 × 4 测试集矩阵。

    原始基座→单一训练集→独立 adapter→四数据集测试
    统一配置
    LoRA rank 16 / alpha 32 / dropout 0.05；BF16；有效 batch 32；固定随机种子。
    当前状态
    已完成的训练集×模型显示真实 WER；尚未完成的单元保留“待补”占位。
